# ifm draw.io Shape Libraries

300+ official ifm product shapes (sensors, IO-Link masters, hubs, switches, vibration, power supplies, M12 cables, and machines) with transparent artwork and pre-configured M12/RJ45 connector snap points.

## Quick Setup (1 Minute)

### Option A — Web Browser (`app.diagrams.net`, fastest — needs internet)
1. Open [drawio-web-config.json](https://mandeepahuja.github.io/ifm-drawio-libraries/drawio-web-config.json) → press **Ctrl+A**, then **Ctrl+C**.
2. Open [app.diagrams.net](https://app.diagrams.net) → **Extras → Configuration…** → click the **`JSON`** tab (top-left).
3. Click inside the box → press **Ctrl+A**, then **Ctrl+V** → click **Apply** → refresh (**F5**).
4. Click **+ More Shapes** (bottom-left) → under **ifm**, check **ifm All Libraries** → click **Apply**.

### Option B — draw.io Desktop (works 100% offline on customer sites)
1. Open the internal SharePoint **Draw.io** folder and click **Sync**.
2. In **File Explorer** → **ifm electronic gmbh** → right-click **ifm.US.Product Management - Draw.io** → select **Always keep on this device**.
3. Open that folder and double-click **`Copy-drawio-config.bat`** *(copies your local config to the clipboard)*.
4. Open **draw.io Desktop** → **Extras → Configuration…** → **`JSON`** tab → **Ctrl+A**, **Ctrl+V** → **Apply**.
5. Close and reopen draw.io Desktop → click **Allow** on the one-time prompt → **+ More Shapes** → check **ifm All Libraries** → **Apply**.

## Updates
New sensors and devices added to existing `.xml` libraries sync automatically — no need to repeat setup.
